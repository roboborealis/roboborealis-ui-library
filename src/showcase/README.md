# Showcase

Granular, single-design-concept Storybook patterns with realistic data — organized
under `Showcase/Patterns/{Tables,Forms,Maps,Dashboards,Intelligence,Information
Displays,Flows}`. Use them as reference examples when building a feature, or as a
live preview of an archetype linked from `src/agent/archetypes.ts`.

**For the full explanation of how Patterns relate to the copy-adaptable Templates in
`src/templates/`, see [Templates vs. Patterns](../../docs/agent-first-architecture.md#templates-vs-patterns--the-storybook-hierarchy)
in `docs/agent-first-architecture.md` — don't re-explain the relationship here, update
it there.**

Do NOT add individual component demos here — those belong in the component's own `*.stories.tsx` file.
