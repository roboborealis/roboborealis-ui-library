# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately via GitHub's
[security advisories](https://github.com/maylortaylor/roboborealis-ui-library/security/advisories/new).
Do not open a public issue for security problems.

Expect an acknowledgement within a few days. Please include repro steps and the affected
component or version.

## Supported versions

Only the latest release is supported. Fixes ship in a new release.
