# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work.
Harassment, discrimination, and personal attacks are not tolerated.

Report unacceptable behavior to the maintainer via a
[private security advisory](https://github.com/maylortaylor/roboborealis-ui-library/security/advisories/new)
or by contacting @maylortaylor directly. Reports are handled confidentially.
